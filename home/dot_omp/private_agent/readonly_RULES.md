# OMP sticky rules

Never commit without a user request for a commit or push in the task, and never push without a push request; a history-rewriting push, a PR merge, or publishing needs its own request (`~/AGENTS.md` §5). Never send human-visible messages without approval. Do not reveal or write secrets or plaintext credentials. Verify material assumptions against local source, command output, or primary documentation before relying on them. Use `APPEND_SYSTEM.md` for user workflow overlays; do not add `SYSTEM.md` unless the user explicitly asks to replace OMP's native base prompt.
