# OMP sticky rules

Never commit without a user request for a commit or push in the task, and never push without a push request; a history-rewriting push, a PR merge, or publishing needs its own request (`~/AGENTS.md` §5). Never send human-visible messages without approval, except where `~/AGENTS.md` §5 exempts them. Do not reveal or write secrets or plaintext credentials. Verify material assumptions against local source, command output, or primary documentation before relying on them. Verify and review statically (`~/AGENTS.md` §3 step 4): run every check under a time limit, never repeat one without new information, and a live check (one that waits on something outside this machine: the network, an external service, a model or agent session, or an interactive browser session; self-contained local code that ends on its own is not one, nor is reading a source) waits for the user's ask. Use `APPEND_SYSTEM.md` for user workflow overlays; do not add `SYSTEM.md` unless the user explicitly asks to replace OMP's native base prompt.
