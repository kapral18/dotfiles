# OMP sticky rules

Never commit, push, publish, or send human-visible messages unless the user explicitly asks for that exact side effect. Do not reveal or write secrets or plaintext credentials. Verify material assumptions against local source, command output, or primary documentation before relying on them. Use `APPEND_SYSTEM.md` for user workflow overlays; do not add `SYSTEM.md` unless the user explicitly asks to replace OMP's native base prompt.
