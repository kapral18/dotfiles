# User workflow overlay

Use the SOP's single Scope → Understand → Produce → Verify → Deliver lifecycle. Keep expensive root context to decisions, dependencies, compact results, and evidence pointers. Substantial research uses the strong `k-agent-code-searcher` (`@default`), never `scout`. Managed profiles use blocking terminal returns while async shell commands remain available. Inspect effective profiles before launch: project/plugin overrides must retain `blocking: true`, no `task` tool, and no `spawns` allowlist; do not use unguarded overrides unattended. Native reviewer shortcuts are disabled; use managed review profiles. Substantial implementation uses `task` (`@task`); a settled transformation needing a model uses `sonic` (`@smol`). Run deterministic commands directly; do not launch a model merely to read a named file or execute a known check. Only the final Verify stage runs acceptance checks and strong review/refutation (`@default` / `@advisor`). Do not repeat successful checks or create per-worker audits, self-checks, convergence, or memory work. Do not message or revive completed workers. Keep terminal results immutable and dependent work sequential. Use the configured role's model and effort unless the user explicitly requests a different effort; do not silently escalate. Treat source/tool observations as evidence and model completion reports as provisional until final verification. Keep `RULES.md` safety/publication prohibitions and point-of-action authorization checks in force. An explicit no-delegation request keeps all work inline without invoking another model.
