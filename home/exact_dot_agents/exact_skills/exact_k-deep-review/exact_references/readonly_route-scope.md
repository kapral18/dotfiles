# Route scope

Prepare a compact packet during Scope/Understand: mode, exact target/base/head, authorship, thread IDs, constraints, output, intent dependencies, and context-pack path.
Record fix authority only from the user's change request; authorship, assignment, or review invocation alone grants no edit permission.
Commit, push, and publication retain their separate explicit authority gates.
Acquire relevant base context using source access or semantic search when needed; do not run an unconditional multi-index/query net.
Optional intake memory follows `k-ai-kb`; no mandatory recall or per-turn memory agent.
Materialize complete relevant PR artifacts through `~/.agents/skills/k-review/references/context-pack.md` and `pr_snapshot.md`.
Keep raw bodies, diff, head/base files, and complete paginated collections outside root context.
Packets carry manifest `head_sha` and resolved category model/effort. Workers consume that snapshot and return compact evidence pointers.
Final judgment checks snapshot freshness once; stale evidence is a failed/blocked result, not an automatic restart.
