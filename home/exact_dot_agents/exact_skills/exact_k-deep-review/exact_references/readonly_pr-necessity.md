# PR Intent Input

During Understand, resolve whether the target PR is still open, coherent, needed, and within the requested scope.
For other/unknown authorship, inspect direct issue/PR dependencies and relevant overlapping work;
do not infer author intent from a title alone.
Use `~/.agents/skills/k-review/references/pr_context_audits.md` for applicable source questions, not as another workflow.
Report uncertainty about mergeability separately from whether review is useful. Review authority does not grant edit/publication authority.
Use a substantial research packet if this requires large context; do not require a separate necessity auditor before every review.
