# Multi-Source Evidence

Collect primary sources and draft the requested synthesis in one bounded research assignment.
Resolve exact source identity, date/ref, and the specific passage supporting each material factual claim.
Keep a compact claim table with claim, primary URL/ref, exact supporting passage, and uncertainty.
For web/doc claims, include the primary-source URL and exact quote; every numeric literal in the claim must occur verbatim in that quote.
Do not infer unsupported numeric claims from related measurements. Respect copyright/source limits.
The final Verify stage audits the material claim set together using those artifacts.
Do not launch per-claim verifiers, deepen after verification, or re-fetch unchanged sources merely for independence.
Unsupported claims are omitted or qualified; unresolved gaps are reported, not a reason to restart research automatically.
Return the synthesis, claim/evidence pointers, and gaps once. No leaf memory writes or other model calls.
